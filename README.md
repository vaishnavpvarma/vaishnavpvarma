### 🧬 Current Focus & Projects

- 🔭 **Currently working on:** Haplotype-resolved CpG methylation profiling (DENV) and optimizing multi-pass parsing logic for clinical data extraction.
- 🌱 **Currently exploring:** Implementing general deep learning architectures for precision medicine and multi-omics integration.
- 👨‍💻 **Recent developments:** 
  - **MaXScriber:** A Python tool automating the extraction and structuring of longitudinal medical laboratory data from heterogeneous PDF reports into Excel.
  - **ScrapeMate:** A local application utilizing BeautifulSoup and gspread for scraping climate data (IMD) and archiving it to Google Sheets and ZIP files.
- 📜 **Intellectual Property:** Holder of **Granted Indian Patent No. 520964** — an apparatus designed to interrupt zoonotic pathogen transmission via contaminated palm sap.
